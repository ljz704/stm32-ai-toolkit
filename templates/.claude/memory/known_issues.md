## 模板示例

## 2026-08-09 HRTIM 死区时间不足导致上下管直通
- **现象**：上电瞬间 MOSFET 炸管，冒烟
- **根因**：HRTIM 死区时间配置为 50ns，实际需要 ≥ 200ns
- **修复**：
  ```c
  HRTIM_DeadTimeConfig(200); // 200ns
  ```
- **预防措施**：
  - 所有 HRTIM 项目默认死区 ≥ 200ns
  - 上电前先用示波器验证死区波形
- **相关**：hrtim_config.c, main.c

## 2026-08-09 RN8209 SPI 初始化过早
- **现象**：RN8209 读取寄存器全为 0xFF
- **根因**：上电后未等待 200ms 就初始化 SPI，RN8209 未就绪
- **修复**：
  ```c
  delay_ms(200);
  RN8209_Init();
  ```
- **预防措施**：
  - 所有 RN8209 项目必须在 main() 开头加 200ms 延时
  - 延时后再拉低 CS 开始通信
- **相关**：main.c, rn8209.c

## 2026-08-09 中断中使用浮点导致 HardFault
- **现象**：程序随机进入 HardFault，CFSR.NOCP=1
- **根因**：F103 无 FPU，中断中执行浮点运算触发协处理器错误
- **修复**：中断中改用定点数或标志位，浮点运算放到主循环
- **预防措施**：
  - 所有 ISR 函数开头检查是否有浮点运算
  - Code Review 时重点检查中断安全
- **相关**：stm32f10x_it.c
