description: 用模板脚手架新建 STM32 工程
---

用模板脚手架新建 STM32 工程：
1. 询问并确认 **项目名** 和 **MCU 型号**（如 `STM32F103C8T6`）。$ARGUMENTS 可按 `--name <名字> --mcu <型号>` 直接传入（脚手架只接受参数，不接受位置参数）。
2. 确认目标目录（默认在当前目录下新建 `./<项目名>` 文件夹，可用 $ARGUMENTS 加 `--dir <路径>` 指定）。
3. 在工具包根目录运行脚手架脚本：
   ```
   python new_project.py --name <项目名> --mcu <型号> --dir <路径>
   ```
4. 脚本执行完成后，展示生成的工程结构，并提示后续步骤（如导入 Keil、配置引脚、开始写外设初始化）。
